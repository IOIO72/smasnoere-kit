# Remix

Due to licensing, I'm not allowed to distribute the remixing files. You have to download the remix files and place them into this folder.

## Multiboard Remixing Files

1. Download the [Snaps STL files from Multiboard](https://multibuild.io/parts/remixing-files?category=other&Part%20Type=Snaps&File%20Type=STL) or directly from [Thangs](https://thangs.com/designer/MultiBuild/3d-model/Snaps%20-%20STL%20Multiboard%20Remixing%20Files-994667)
2. Extract the archive
3. Place the file named `Blank Snap Standard.stl` into this folder named `remix`
